STEP 01 · PROPOSAL

File a new case

Define one answerable question and bind it to two publicly auditable evidence records.

Case details

Filing creates a PROPOSED case and freezes the challenge duration. It does not issue a ruling or start the deadline.

Read the guide
TRANSACTION STATUS

Before you file

  • Both sources must use HTTPS and different hostnames.
  • Hostname separation does not prove independent ownership.
  • Verify that genuinely independent publishers control the records.
  • Prefer stable, public, versioned records over mutable pages.

What happens next?

Go to the Review desk and request assessment. Validators fetch both records, store their digests, and start the full frozen challenge duration.
